# CS 视频播放器

[English](README.md) | 中文

基于 Python 3.12+、Flet 0.86.5 和 flet-video 构建的 Windows 桌面本地视频播放器。
交互设计灵感来自 PotPlayer，格式兼容性对标 VLC。

## 功能特性

- **全格式支持** — MP4、MKV、AVI、MOV、FLV、WebM、WMV、MPG、TS、RMVB 等
- **声明式 UI** — 基于 `@ft.component` hooks API（`use_state`、`use_effect`、`use_ref`）构建
- **播放列表管理** — 添加文件/文件夹，按名称/大小/日期排序，拖拽排序
- **多文件选择** — 一次选择多个文件或打开整个文件夹
- **播放模式** — 顺序播放、列表循环、单曲循环、随机播放
- **播放控制** — 播放/暂停、停止、上一曲/下一曲、快进/快退（默认10秒，Shift加倍）
- **进度条** — 可拖拽跳转并实时显示时间标签，点击时间文字可切换剩余时间显示
- **音量系统** — 滑块调节、静音切换、鼠标滚轮调节音量，音量值持久化记忆
- **倍速播放** — 0.25x ~ 16x，保留常用档位快捷按钮（0.25x–4.0x）
- **全屏模式** — 双击视频或按 `F`/`F11` 进入全屏，控制栏自动隐藏，鼠标移到底部时显示
- **键盘快捷键** — 空格、←/→、↑/↓、M、F、F11、N、P、S、T、Esc、Delete
- **最近文件** — 持久化保存最近 30 个打开的文件记录
- **设置持久化** — 音量、播放倍速、播放模式、侧栏宽度、时间显示模式
- **会话恢复** — 退出时自动保存播放列表、当前曲目与播放进度，下次启动时可选择继续播放
- **硬件加速** — 基于 mpv/libmpv 后端
- **截图** — 通过 `Video.take_screenshot()` 截取当前画面

## 项目结构

```
cs-video-player/
  main.py                    # 入口文件
  pyproject.toml             # 项目配置与依赖
  configs/
    app_config.py            # 常量与配置
    theme.py                 # 配色与字体
  core/
    models.py                # 数据模型（PlaylistItem、PlayerState、枚举）
    video_engine.py          # flet-video 封装（异步安全）
    player_controller.py     # 状态管理桥接层
  components/
    app.py                   # 根组件（键盘、FilePicker、会话恢复、布局）
    sidebar.py               # 播放列表、文件打开、最近文件、拖拽排序
    player_area.py           # 视频显示 + 控制栏
    ui_helpers.py            # 可复用组件工厂
  utils/
    formatters.py            # 时间/大小格式化、事件数据解析
    storage.py               # JSON 持久化（最近文件、设置、播放位置、会话）
    file_scanner.py          # 视频文件扫描与批量创建
```

## 使用

```bash
python main.py
```

### 键盘快捷键

| 按键 | 功能 |
|------|------|
| `空格` | 播放 / 暂停 |
| `←` / `→` | 后退 5 秒 / 前进 5 秒 |
| `↑` / `↓` | 音量 +5 / -5 |
| `M` | 切换静音 |
| `F` | 切换全屏 |
| `N` / `P` | 下一首 / 上一首 |
| `Esc` | 退出全屏 |
| `Delete` | 从播放列表中移除当前项 |

## 技术栈

- **Python 3.12+**
- **Flet 0.86.5** — 声明式 UI 框架（`@ft.component`、hooks API）
- **flet-video 0.86.5** — 视频播放控件（mpv/libmpv 后端）
- **面向对象设计** — 控制器/引擎/模型分层架构
- **状态驱动 UI** — `PlayerState` 作为唯一数据源，通过监听回调实现响应式更新
